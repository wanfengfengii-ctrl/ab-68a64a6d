# 复合材料铺层修复工作台（Laminate Lay-up Repair Workbench）

纯前端（TypeScript + React + Vite）工作台：工程师在浏览器中导入或编辑**参考铺层**，
启动综合后逐位比较原序列与修复结果。全部计算在浏览器本地完成，**不调用任何业务后端**；
容器中也只有 nginx 静态托管。

## 铺层规则与优化目标

合法序列含 **4–48 个偶数层**，角度仅可为 `0°`、`+45°`、`−45°`、`90°`。修复结果须同时满足：

1. **各角度数量保持**（只是重排，不增删层）；
2. **关于中面对称**：s[i] = s[n−1−i]；
3. **+45° 与 −45° 数量相等**；
4. **表面（第 1 层与最后一层）非 90°**；
5. **相邻角差按 180° 周期计 ≤ 45°**（+45° 与 −45° 相差 90°，不允许相邻；−45° 与 90° 折回后差 45°，允许）；
6. **同角连续不超过 3 层**（含中面接缝处拼成的连续段）。

求解为**全局**依次最小化（不是局部交换，也不是找到首个可行排列就停止）：

- 第一级：**改动位置数 D**（与参考序列逐位不同的位置总数）；
- 第二级：在第一级最优前提下，最小化**相邻角度变化次数 T**；
- 第三级（裁决）：前两级相同的方案中，按规定角度次序 `0° → +45° → −45° → 90°`
  取**字典序最小**的完整铺层。

### 算法（精确全局最优）

偶数层中面对称 ⇒ 每个角度计数必须为偶数，序列完全由半幅 `h` 决定：`s = h + reverse(h)`。

在 `(各角度已用配额, 末角度, 末尾同角连跑长度)` 状态空间上做**分层动态规划**：

- 表面约束：半幅首层禁用 90°；
- 相邻约束：展开每个角度，按 180° 周期角差 ≤ 45° 剪枝；
- 连跑约束：同角连跑到 4 即剪枝；中面接缝会把半幅末尾连跑翻倍，故终态要求半幅末尾连跑长度为 1；
- 每位置选角的改动代价按镜像位置对计入 `d_i(v) = [v≠参考[i]] + [v≠参考[n−1−i]]`；
- 同一状态仅保留 `(D, 半幅变化数 C, 前缀字典序)` 最优的一个前缀；
  完整序列的相邻变化数 `T = 2C`（中面接缝为同角，不计变化）。

半幅最多 24 层、4 种角度，状态空间很小：n=48 最坏计数分布下单次求解约 20 ms（见 `scripts/perf.ts`）。
测试中用**全排列暴力枚举**对 n≤10 的大量随机/固定案例独立核对 `(D, T, 字典序)`，结果逐案一致。

## 页面功能

- 参考铺层：手工编辑或导入 `.txt/.csv`（空格、逗号、顿号、分号、斜杠、换行均可分隔），
  实时显示层数与各角度计数；
- 启动综合后展示：
  - **两级目标值**（D、T）与字典序裁决说明；
  - **逐层差异对照表**（原序列 / 修复后 / 改动状态，改动位橙色高亮）；
  - **六条规则的可复核证据卡片**，每张可展开查看逐镜像对 / 逐界面 / 逐连续段明细；
    证据模块独立于求解器，重新校验结果；
- **输入非法**（层数、记号、±45 等量等）或**确实无解**时，立即清除旧结果并给出具体原因。

## 本地开发

```bash
npm ci
npm run dev        # 开发服务器 http://localhost:5173
npm run test:run   # 单元 + 全局最优性质测试（vitest）
npm run build      # 类型检查 + 产出 dist/
```

## Docker / Docker Compose

构建并启动静态 Web（nginx）：

```bash
cp .env.example .env      # 可选：修改宿主机端口
docker compose up -d --build
# 浏览器打开 http://localhost:${WEB_PORT:-8080}
curl http://localhost:8080/healthz   # → ok
```

- 宿主机端口由 `WEB_PORT` 配置（默认 `8080`），容器内固定 80；
- 已配置容器健康检查（`/healthz`，compose 与 Dockerfile 均含）。

验收服务 `verify`（一次性，退出码 0 表示通过）：

```bash
docker compose build verify
docker compose run --rm verify
```

它会：等待 web 健康通过 → 运行单元/性质测试 → HTTP 冒烟（健康端点、首页、哈希静态产物）
→ 求解三态（非法 / 无解 / 成功）端到端冒烟。
